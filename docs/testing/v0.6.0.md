## Limits

The native tests use real Hermes persistence, dispatch and delivery APIs with deterministic model/child runners. They do not assess live-provider judgment. Ambiguous in-flight tool effects require explicit user continuation. Git evidence requires an existing Git commit and excludes ignored files; successful checks do not prove the entire task is correct. No live installation, profile, credentials or production data was migrated; no image, package, tag or Git commit was published remotely. A running-installation update remains a separate dry-run/approval operation.

Docker pins Hermes v2026.8.31 and Olympus Node 22.22.3 independently, retaining Hermes's own Node 26 toolchain. Manifest digests were verified for both Intel and ARM. Local Docker build validation is recorded at finalization; manifest availability alone is not a successful image build or deployment.
